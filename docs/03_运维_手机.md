## 2. 唯一入口：Linux Deploy 网页终端

- 手机保持 Linux Deploy app 运行（httpd 守护模式）
- 每次操作前先访问 `http://192.168.31.208:5080/cgi-bin/terminal` **触发 5081 端口的一次性 WebSocket 监听**，再用电脑脚本连
- 电脑辅助脚本（在 `C:\ComfyUI\`）：
  - `rawterm.ps1`：WebSocket 终端客户端。先 GET 终端页触发 5081，再 `-B64 <base64命令> -Port 5081`
  - `runcmd.ps1`：自动完成"触发+执行"两步（`-B64 <base64命令>`）
  - `httpserver.ps1 -Root C:\mc\rom -Port 8001`：PC 文件服务器（手机侧 curl/wget 拉文件用）
- **命令帧上限约 125 字节**：长命令/含引号命令会截断 → 一律写成脚本文件传到容器再执行（文件放 `C:\mc\rom\`，手机 `curl -o /data/local/mnt/tmp/x.sh http://192.168.31.180:8001/x.sh`）
- 提权/进容器：
  - 主机 root：`su -c "命令"`
  - 容器内：`su -c "chroot /data/local/mnt /bin/sh -c 'export PATH=/usr/bin:/bin:/usr/sbin:/sbin; 命令'"`
  - 注意：**chroot 内 PATH 必须显式 export**，否则找不到命令
- 长任务后台跑：`nohup 命令 >/日志 2>&1 &` 防终端断开被杀
- 传文件：PC `httpserver.ps1 -Port 8001` + 手机 `/system/bin/curl -o /data/local/mnt/tmp/xx http://192.168.31.180:8001/xx`

### 4.3 apt 源（✅ 已修复 2026-08-16 深夜，勿再动）
- **现象**：curl 连 aliyun/ustc 都 200，但 apt 报 `socket (13: Permission denied)`（aliyun）或 `Could not resolve`（ustc，DNS 走 UDP socket 也被拒）
- **根因**：Android 系统**限制非 root UID 创建 socket**；apt 下载子进程默认以 `_apt`(uid 42) 运行 → socket 被拒（python `setuid(100)` 复现 FAIL，root 则 OK）
- **修复（已持久化）**：`/etc/apt/apt.conf.d/90android-sandbox` 写入 `APT::Sandbox::User "root";`
- **源**：USTC `deb http://mirrors.ustc.edu.cn/debian bookworm main contrib non-free`（/etc/hosts 固定 `202.141.160.110 mirrors.ustc.edu.cn`）；速度 ~2.2MB/s
- 旧 hosts 行 `222.211.12.75 mirrors.aliyun.com` 保留无妨（aliyun 也可用）；tuna http 403 不用
- apt 相关脚本备份在 `C:\mc\rom\`（apt-fix.sh 等旧脚本是修复前产物，可忽略）
