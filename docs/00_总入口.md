# docs/00 · 项目总入口（每个新会话先读这一份）

> my-wiki 个人知识库。**本文件是项目地图**：告诉 AI 会话该读哪些文档、项目现状一句话、关键约束。
> 更新日期：2026-08-16

## 一句话现状

Node.js 零依赖单进程知识库服务（`node:http` + `node:sqlite` + WebSocket + fetch），网页管理 + QQ 机器人（NapCat/OneBot11）双入口，DeepSeek AI 自然语言操作。跑在电脑（开发/主用）和手机服务器（Linux Deploy Debian 12 arm64，生产）两端。

## 会话分工（按域分，省 token 的关键）

| 会话 | 职责 | 开工必读 | 收工必写 |
|---|---|---|---|
| **wiki 开发** | 所有功能开发（权限/AI/提醒/前端等） | 本文件 + `01` + `02` | 更新 `02`；决策写进 `01` |
| **手机运维 / NapCat** | 手机服务器、NapCat 安装、git 同步 | 本文件 + `03` | 更新 `03` |
| 临时任务 | 一次性咨询/脚本 | 只读相关小节 | 有决策就写进 `01` |

## 开新会话的第一句话（模板）

> （手机运维会话把后两份换成 `docs/03_运维_手机.md`）

## ⚡ 更省事的方式：skill 一键初始化（推荐）

项目里已装两个 skill，开新会话时**直接说一句话**即可自动完成读文档 + 报告进度：

| 你说 | 效果 |
|---|---|
| `wiki开发新会话` 或 `/wiki-dev` | 自动读 `00/01/02`，报告进度与待办 |
| `手机运维新会话` 或 `/phone-ops` | 自动读 `00/03`，报告状态与下一步 |

skill 定义在 `.dsh/skills/`（wiki-dev / phone-ops），想改初始化逻辑就改那两个文件。

## 铁律（每个会话必须遵守）

1. **决策立即落盘**：讨论出结论 → 一行写进 `01_需求与决策.md`，不靠会话记忆。
2. **状态即更新**：任务完成/卡点变化 → 更新 `02` 或 `03`。
3. **不重复解释历史需求**：让 AI 读文档，别在聊天里复述。
4. **开发流程**：电脑本地测试 → 用户确认 → `git push` → 手机 `git pull` 同步。DSH 不部署手机。
5. 改后端重启 8000 服务；改前端只需刷新。Node >= 22.5（node:sqlite）。不引入 Python/Docker。
