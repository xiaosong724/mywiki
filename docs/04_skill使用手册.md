# docs/04 · Skill 使用手册（忘了就打开这份）

> 这套 skill 让"开新会话 / 记决策 / 收尾"一句话搞定，不用背模板。
> 使用前提：工作目录在 `C:\my-wiki`（项目根），DSH 运行中。
> 更新日期：2026-08-16

## 一、总共 4 个 skill 一览

| Skill | 什么时候用 | 怎么触发 | 它自动做什么 |
|---|---|---|---|
| `fg-wiki-dev` | 开「wiki 功能开发」新会话 | 说 `fg wiki开发新会话` 或输 `/fg-wiki-dev` | 读 `docs/00` `01` `02`，报告当前进度与待办，确认理解后等你下任务 |
| `fg-phone-ops` | 开「手机运维 / NapCat」新会话 | 说 `fg手机运维新会话` 或输 `/fg-phone-ops` | 读 `docs/00` `03`，报告手机服务状态、NapCat 卡点与下一步 |
| `fg-record-decision` | 讨论出结论了，要记下来 | 说 `fg记下这个决策：...` 或输 `/fg-record-decision` | 把结论按"一行一条"追加进 `docs/01_需求与决策.md`，跨会话复用 |
| `fg-wrap-up` | 要结束/换会话前 | 说 `fg收尾` 或输 `/fg-wrap-up` | 回顾本会话 → 更新 `01` 决策、`02` 看板、`03` 运维（如涉及）→ git 提交推送 → 提示下一步开哪个会话 |

> 所有触发词统一带 **`fg`** 前缀（自然语言"fg xxx"或斜杠命令 `/fg-xxx`），方便辨认是本项目的 skill。

## 二、日常完整流程（照着做就行）

```
① 开新会话      → 说「fg wiki开发新会话」或「fg手机运维新会话」
② 干活          → 正常聊，让 AI 做事
③ 出结论了      → 说「fg记下这个决策：<结论>」
④ 干完/要换会话 → 说「fg收尾」
⑤ 开下一个会话  → 重复 ①（收尾时会告诉你该开哪个）
```

## 三、两种触发方式（任选）

1. **自然语言**（推荐）：`fg wiki开发新会话`、`fg记下这个决策：群主不豁免`、`fg收尾`
2. **斜杠命令**（更确定）：`/fg-wiki-dev`、`/fg-phone-ops`、`/fg-record-decision`、`/fg-wrap-up`

两者效果一样；记不住名字时用自然语言"fg + 意图"就行，AI 会根据描述自动匹配。

## 四、Skill 文件在哪、怎么改

所有 skill 都在项目的 `.dsh/skills/` 目录下，一个文件夹一个 skill：

```
.dsh/skills/
├── fg-wiki-dev/SKILL.md          # 开 wiki 开发会话的初始化逻辑
├── fg-phone-ops/SKILL.md         # 开手机运维会话的初始化逻辑
├── fg-record-decision/SKILL.md   # 记决策的落盘逻辑
└── fg-wrap-up/SKILL.md           # 收尾归档逻辑
```

- 想改"初始化读哪些文档""收尾要不要自动推送 git"等行为 → 直接改对应 `SKILL.md`
- 改完**立即生效**（DSH 实时监听），无需重启
- 文件跟着 git 走，手机端也能同步同一份

### ⚠️ 两份副本，改完要同步（重要）

skill 同时存在**两个位置**，各司其职：

| 位置 | 作用 |
|---|---|
| `C:\my-wiki\.dsh\skills\`（项目级） | **权威版本**，跟着 git 走，改 skill 在这里改 |
| `C:\Users\49553\.dsh\skills\`（用户级） | 兜底可见性——**任何工作目录**开的新会话都能看到（项目级只在工作目录是 `C:\my-wiki` 时才可见） |

**改完项目级 skill 后必须手动同步到用户级**，否则新会话（工作目录不在项目内时）看到的还是旧版：

```powershell
Copy-Item C:\my-wiki\.dsh\skills\* C:\Users\49553\.dsh\skills\ -Recurse -Force
```

或者直接对新会话/AI 说「同步skill」，它会帮你执行。

## 五、配套文档（docs/ 是什么）

| 文档 | 内容 |
|---|---|
| `docs/00_总入口.md` | 项目地图：会话分工、skill 用法表、文档索引、铁律 |
| `docs/01_需求与决策.md` | 决策日志：所有已定决策一行一条（skill 读写这个） |
| `docs/02_待办与进度.md` | 任务看板：状态 \| 卡点 \| 下一步 |
| `docs/03_运维_手机.md` | 手机服务器 + NapCat 部署（自包含） |
| `docs/04_skill使用手册.md` | **本文件**：skill 怎么用 |

> 记不住 docs 编号没关系：每个新会话 AI 都会先读 `docs/00` 这张地图，它会告诉你该看什么。
