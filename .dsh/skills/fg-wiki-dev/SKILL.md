# 会话初始化：wiki 功能开发

## 第一步：读文档

依次读取以下文件（都在项目根 `C:\my-wiki` 下）：

1. `docs/00_总入口.md` — 项目地图、铁律、开发流程
2. `docs/01_需求与决策.md` — 所有已定决策（**不要重复询问/重新推理已决策的事**）
3. `docs/02_待办与进度.md` — 当前待办与进度看板

如果 `docs/` 不存在或缺失，回退读根目录的 `项目交接_DeepSeekHarness.md`。

## 第二步：报告

读完向用户报告（简洁，不要长篇复述）：

- 当前进度一句话（按 `02` 看板）
- 待办里最相关的事项
- 确认理解，等待用户给出本次要做的任务

## 第三步：开始

用户给出任务后按 `00` 的铁律执行：

- 改后端 → 重启 8000 服务；改前端 → 只需刷新
- 决策出结论 → 一行写进 `docs/01_需求与决策.md`
- 任务完成/卡住 → 更新 `docs/02_待办与进度.md`
- 保持 Node 零依赖架构，不引入 Python/Docker
