# 会话收尾归档

## 作用

换会话前把本会话的一切**可复用信息**落盘，让新会话零依赖。执行完输出一份"收尾报告"。

## 流程

1. **回顾本会话**：从对话历史整理出——新产生的决策、完成/卡住的任务、手机运维状态变化、新增/修改的文件。

2. **更新 `docs/01_需求与决策.md`**（决策日志）：
   - 有讨论出结论但还没落盘的 → 按"决策一行一条"追加（参考 `record-decision` skill）
   - 没有新决策就跳过

3. **更新 `docs/02_待办与进度.md`**（看板）：
   - 本会话完成的任务 → 状态改 ✅ 并挪进"近期完成记录"
   - 新卡点/新待办 → 加行，写清状态与下一步
   - 更新日期

4. **如果涉及手机运维** → 更新 `docs/03_运维_手机.md`：服务状态、NapCat 进度、卡点、下一步。

5. **git 提交推送**（如用户在电脑端工作目录）：`git add -A && git commit -m "..." && git push origin main`，让手机端也能同步。

6. **输出收尾报告**（简洁清单）：
   - 本会话完成的事
   - 更新了哪些文档（01/02/03）
   - 建议下一步：开哪个新会话（wiki-dev / phone-ops）+ 第一句说什么

## 注意

- 不把聊天记录原文复制进文档，只提炼结论/状态。
- 若用户明确说"先别推 git"则不推送。
